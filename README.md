# Ma Garderie 🧸

Application mobile de gestion des menus d'une garderie d'enfants.

## Présentation
- Écran de démarrage (splash) avec transition automatique après 3 s.
- Page principale : AppBar avec recherche et notifications, Drawer (Accueil / Menus / À propos), FAB (+).
- Liste des menus du jour (données statiques locales) avec icône, titre et description.
- Interactions : Snackbars sur boutons, FAB, Drawer et éléments de liste.

## Technologies utilisées
- **Flutter** (Dart)
- **Git / GitHub** (travail par branches + PR/merges)
